TAMON Google連携のプライバシーポリシー

株式会社BBBandCompanyは、運用者本人が使うアシスタント「TAMON」のGoogle連携について、以下の方針で情報を扱います。Googleの認証画面では、従来のアプリ名「JARVIS」が表示される場合があります。

取得する情報と用途

Googleの認証で許可された範囲内で、アカウントの識別情報、Gmailのメール・添付ファイル、Google Driveのファイル、ドキュメント・スプレッドシート・スライド、カレンダーの予定、本人が選択した写真、Google Analytics・Search Consoleの情報を取得します。

これらの情報は、本人の依頼に応じた検索、要約、資料作成、予定管理、分析に使用します。メールの作成・送信やファイル・予定の変更は、本人の指示と許可の範囲で行います。認証で許可される範囲と、個々の依頼で実際に取得する範囲は異なります。

情報の処理と保存

認証情報はTAMONの運用環境に保存し、API接続とアクセストークンの更新に使用します。依頼で扱った情報や実行結果は、TAMONの会話記録、作業ファイル、運用記録に保存される場合があります。

依頼の実行にはGoogle、TAMONの運用基盤、および依頼に使用するAIサービスなどの処理基盤を利用します。情報が各基盤に送られる場合があり、各サービス側での取り扱いは、そのサービスの契約・設定・規約にも従います。

利用の制限

Google連携で得た情報を販売したり、広告配信のために利用したりしません。本人の依頼を実行する目的で使用し、汎用AIモデルの学習用データとして提供しません。Google APIから取得する情報の利用と他のアプリへの転送は、限定的な使用に関する要件を含むGoogle API Services User Data Policyに従います。

連携の解除と削除

本人はGoogleアカウントの接続管理でアクセス権を取り消せます。取り消し後も、すでにTAMONに保存された情報が残る場合があります。認証情報や保存済み情報の削除は、運用者への連絡で依頼できます。外部サービスの記録については、そのサービスの削除機能や保持条件にも従います。
